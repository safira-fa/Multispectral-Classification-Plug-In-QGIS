**Модуль для автоматической классификации мультиспектральных аэрофотоснимков с целью выявления нефтяных загрязнений и нарушенных земель с помощью методов библиотеки scikit-learn.**

*Для загрузки плагина - скачать архивом zip и установить в QGIS.*

- init.py - запуск плагина
- plugin.py - основной код плагина
- db_storage.py - связь с БД POstreSQL
- classifiers.py - алгоритмы МО
- dialog.py - логика диалогового окна
- dialog_base.ui - графический интерфейс через Qt
- icon.png - иконка плагина
- metadata.txt - инфо о плагине
